# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-24

### Added
- C++17 core library (`glyphcast_core`) with PPM and 24-bit BMP loaders and a renderer.
- Command-line tool with width, ramp, invert and colour options.
- Python port using only the standard library, with unit tests.
- Browser version with drag-and-drop input, live preview, copy and download.
- Three built-in character ramps: `classic`, `minimal` and `dense`.
- GitHub Actions workflow covering the C++, Python and web builds.
